# Quick Start Guide

## For Windows Users - The Fastest Way

### Step 1: Install Python (One-time setup)

1. Download Python from https://www.python.org/downloads/
2. Run the installer
3. **IMPORTANT**: Check the box "Add Python to PATH" before clicking Install
4. Click "Install Now"

### Step 2: Install Dependencies (One-time setup)

1. Double-click `install_dependencies.bat`
2. Wait for installation to complete
3. Press any key when done

### Step 3: Run the Application

1. Double-click `start.bat`
2. The application will open in your browser automatically
3. You're ready to import builds!

## How to Import a Build

1. **In Path of Building:**
   - Open your build
   - Click "Import/Export Build"
   - Click "Generate"
   - Click "Copy"

2. **In PoE Build Guide:**
   - Paste the code in the text box
   - Click "Import Build"
   - Done! Click on your build to view it

## Features Overview

### Leveling Guide
- Track your progress through each act
- Check off milestones as you complete them
- See recommended levels for each checkpoint

### Skills & Gems
- View all skill gems from your build
- See gem levels and quality requirements
- Organized by skill group

### Gear
- See what items your build uses
- Organized by equipment slot
- Plan your upgrades

### Progress Tracking
- Save your current level and act
- Track completed milestones
- Never lose your place

## Tips

- You can import multiple builds and switch between them
- Your progress is saved automatically when you click "Save Progress"
- Completed milestones stay checked even if you close the app
- Delete builds you no longer need with the "Delete Build" button

## Troubleshooting

**Problem**: "Python is not found"
**Solution**: Reinstall Python and make sure to check "Add Python to PATH"

**Problem**: Dependencies won't install
**Solution**: Check your internet connection and run `install_dependencies.bat` again

**Problem**: Browser doesn't open automatically
**Solution**: Open your browser and go to http://localhost:5000

**Problem**: Port already in use
**Solution**: Close any other applications that might be using port 5000
